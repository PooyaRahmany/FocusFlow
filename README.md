# FocusFlow

FocusFlow is a personal productivity app built to make everyday planning and task management easier.

I created this project to bring different productivity tools together in one place, so users can organize their tasks, plan their schedules, track their progress, and manage their focus without switching between multiple apps.

## Features

- **Tasks:** Create, organize, and manage daily tasks.
- **Calendar:** Keep track of schedules and upcoming activities.
- **Progress:** View completed tasks and monitor productivity.
- **Pomodoro:** Use focused work sessions to manage your time.
- **Planner:** Organize plans and stay on track.
- **Music:** A dedicated section for focus and productivity music.
- **Bonfire:** Save and organize useful prompts in one place.
- **Customization:** Personalize themes, colors, and preferences.
- **Language Support:** Switch between English and Persian.
- **Responsive Design:** Works on desktop and mobile screens.

## Built With

- HTML
- CSS
- JavaScript

## Getting Started

You can run FocusFlow locally without installing additional tools.

1. Clone this repository:

   ```bash
   git clone https://github.com/PooyaRahmany/FocusFlow.git
   ```

2. Open the project folder.
3. Open the main HTML file in your browser.
